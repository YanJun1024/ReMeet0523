# TagWord APP 设计文档

## 1. 产品概述

**产品名称**: TagWord  
**产品定位**: 标签式语言学习工具  
**核心功能**: 通过 `#标签` 格式快速关联单词、笔记和词典释义

## 2. 页面结构

### 2.1 页面清单

| 页面 | 路径 | 说明 |
|------|------|------|
| 编辑页 | `/pages/index/index` | 首页，核心功能页面 |
| 笔记列表页 | `/pages/notes/notes` | 显示标签相关的所有笔记 |
| 词典页 | `/pages/dict/dict` | 显示单词词典释义 |
| 标签管理页 | `/pages/tags/tags` | 管理所有标签 |
| 用户中心页 | `/pages/user/user` | 个人中心 |

### 2.2 页面流转

```
编辑页 ←→ 笔记列表页 (左滑)
编辑页 ←→ 词典页 (右滑)
编辑页 → 标签管理页 (点击标签管理)
标签管理页 → 用户中心页 (点击头像)
标签管理页 → 词典页/笔记列表页 (点击标签选项)
```

## 3. 功能设计

### 3.1 编辑页

**布局**:
- 顶部: 空（预留状态栏）
- 中部: 卡片区域（可滑动）
- 底部: 编辑输入框 + 保存按钮

**卡片设计**:
- 显示当前最后输入的标签
- 显示该标签最近一条笔记（8行高度）
- 左右滑动标识位于内容区域两侧中部
  - 左侧: `◀ 笔记`
  - 右侧: `词典 ▶`

**编辑功能**:
- 输入 `#单词 ` 自动识别为标签
- 标签高亮显示
- 保存按钮位于输入框右下角

### 3.2 笔记列表页

**布局**:
- 顶部: 返回按钮 + 页面标题
- 中部: 笔记卡片列表（每行一个卡片）

**卡片设计**:
- 日期
- 标题
- 内容摘要
- 查看详情按钮

### 3.3 词典页

**布局**:
- 顶部: 返回按钮 + 发音按钮
- 中部: 词典内容

**内容**:
- 单词 + 音标
- 释义列表
- 例句
- 我的笔记
- 网络释义

### 3.4 标签管理页

**布局**:
- 顶部: 页面标题
- 用户信息区: 头像 + 用户名 + 设置图标
- 搜索框
- 标签列表

**标签排序规则**:
1. 状态（学习中 > 已学会）
2. 笔记数量（降序）
3. 字母顺序（升序）

**标签选项弹窗**:
- 进入词典
- 进入相关笔记
- 标记为已学会
- 取消

### 3.5 用户中心页

**布局**:
- 顶部: 返回按钮 + 页面标题
- 用户信息: 头像 + 用户名 + 学习天数
- 学习统计: 笔记数、标签数、连续天数
- 功能设置列表

## 4. 视觉设计

### 4.1 色彩规范

| 颜色 | 色值 | 用途 |
|------|------|------|
| 主色 | `#4A90E2` | 标签、按钮、高亮 |
| 背景色 | `#FFFFFF` | 页面背景 |
| 卡片背景 | `#F8F9FA` | 卡片区域 |
| 文字主色 | `#333333` | 正文 |
| 文字次色 | `#666666` | 次要文字 |
| 文字辅助 | `#999999` | 提示文字 |
| 边框色 | `#E8E8E8` | 边框、分隔线 |

### 4.2 字体规范

- 使用系统默认字体
- 标题: 18px, 加粗
- 正文: 14px
- 辅助文字: 12px

### 4.3 间距规范

- 页面边距: 16px
- 卡片内边距: 16px
- 卡片间距: 12px
- 元素间距: 8px

## 5. 交互设计

### 5.1 手势交互

| 手势 | 页面 | 效果 |
|------|------|------|
| 左滑卡片 | 编辑页 | 进入笔记列表页 |
| 右滑卡片 | 编辑页 | 进入词典页 |
| 点击标签 | 编辑页 | 切换当前标签 |

### 5.2 点击交互

| 点击元素 | 效果 |
|----------|------|
| 保存按钮 | 保存当前笔记 |
| 标签管理 | 进入标签管理页 |
| 头像 | 进入用户中心页 |
| 标签 | 弹出选项菜单 |
| 返回按钮 | 返回上一页 |

## 6. 数据存储

### 6.1 本地存储

- 笔记数据: `uni.getStorageSync('notes')`
- 标签数据: `uni.getStorageSync('tags')`
- 用户设置: `uni.getStorageSync('settings')`

### 6.2 数据结构

```javascript
// 笔记
{
  id: String,
  content: String,
  tags: [String],
  createTime: Number,
  updateTime: Number
}

// 标签
{
  name: String,
  noteCount: Number,
  status: 'learning' | 'mastered',
  createTime: Number
}
```

## 7. API 接口

### 7.1 词典API

- 使用 Free Dictionary API
- 接口: `https://api.dictionaryapi.dev/api/v2/entries/en/{word}`
- 返回: 音标、释义、例句等

### 7.2 数据同步（可选）

- 云开发实现数据备份和同步

## 8. 技术栈

- 框架: uni-app (Vue3)
- 语言: TypeScript
- 状态管理: Pinia
- UI组件: uni-ui
- 手势库: 自定义touch事件
